## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/PixelIris.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

PixelIris is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
